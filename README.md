# Landing de la beta – SaaS anti-procrastinación con mascota

Sitio estático (HTML + CSS + JS). No hay dependencias ni paso de compilación, así que no existe carpeta `node_modules`.

## Contenido

| Archivo | Para qué sirve |
|---|---|
| `index.html`, `styles.css`, `script.js` | La landing y la lógica del formulario |
| `config.js` | URL y clave **pública** de Supabase, y el nombre de la app |
| `supabase.sql` | Crea la única tabla `beta_signups` (FN0) y sus permisos |
| `assets/` | Imágenes de los 6 wireframes que se muestran en la landing |
